The stack behind SaaSKit is:

- **Next.js** for marketing, docs, and app UI.
- **PostgreSQL** powering tenant-safe schemas.
- **Clerk** for authentication flows.
- **Stripe** for billing, trials, and webhook handling.
- **Node 20** deployments via Nixpacks + Dokploy.

Keep this architecture in mind when adapting new modules.
