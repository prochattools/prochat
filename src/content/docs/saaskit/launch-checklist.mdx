Checklist for go-live:

1. Copy `.env.example` and fill in database, Clerk, and Stripe settings.
2. Run migrations and verify Postgres connectivity.
3. Deploy to your Node 20 host or Vercel (`npm run build`).
4. Add Stripe live keys and webhook secrets.
5. Smoke test login, dashboard, and billing flows.
