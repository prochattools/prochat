ProKit is built on a solid stack:

- **Next.js app** that handles marketing pages, docs, and the dashboard.
- **PostgreSQL with schema-per-tenant** for isolation and scalability.
- **Clerk authentication** for passwordless signup, verification, and MFA.
- **Stripe billing flows** with usage tracking and webhook automation.
- **Deployment** using Node 20, Nixpacks, Dokploy, and optional Vercel hosting.

This architecture keeps the product fast, secure, and easy to extend.
