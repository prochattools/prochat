Use this checklist to go live:

1. Configure `.env` with database, Clerk, and Stripe credentials.
2. Connect the app to your Postgres instance and run migrations.
3. Deploy to Vercel or your Node 20 host (build command: `npm run build`).
4. Add Stripe secret and webhook keys.
5. Flip secrets to production mode and verify live login, dashboards, and billing.
