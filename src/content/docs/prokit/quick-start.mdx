Use this page when you already know ProKit is the right fit and want to get the runtime foundation working locally.

## Quick start sequence

1. Clone the repository: `git clone https://github.com/stevewesthoek/prokit`
2. Install dependencies with `npm install`
3. Copy the environment file and fill the required values for database, Clerk, Stripe, and email
4. Start the app locally with `npm run dev`
5. Confirm the homepage, auth routes, and dashboard shell load correctly

## What to verify

- the app boots without environment errors
- database connectivity is working
- auth pages load correctly
- billing is configured in test mode before you move further
- you know which product-specific docs page you need next
