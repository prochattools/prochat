# What do you want to learn about?

ProChat has two current product paths. Start with the general Memory model, evaluate its first QA-specific edition, or explore how Workbench gives ChatGPT a guarded way to work with local projects.

## ProChat Memory

ProChat Memory is the flagship, niche-agnostic memory model for preserving useful evidence, reviewing what deserves to last, correcting outdated conclusions, and retrieving only the context that matters.

Use this path to understand:

- capture and reviewed memory;
- evidence and provenance;
- correction and supersession;
- selective retrieval;
- local ownership and model independence;
- the boundary between AI recommendations and human decisions.

[Explore ProChat Memory](/memory)

There is no separate public repository for general ProChat Memory today. The current public implementation is the Memory for QA edition.

## ProChat Memory for QA

Memory for QA is a **public source-available selected beta**. It is not open source, and it is free only for approved beta participants.

Use this path to:

- inspect the public repository;
- understand the selected-beta evaluation model;
- apply for beta access;
- report sanitized feedback through GitHub Issues or ProChat Discussions.

[Explore Memory for QA](/memory-qa)

[View the Memory for QA repository](https://github.com/prochattools/memory-qa)

[Apply for the selected beta](/contact?topic=memory-qa-beta#contact-form-card)

[Report sanitized feedback](https://github.com/prochattools/memory-qa/issues)

[Join ProChat discussions on GitHub](https://github.com/orgs/prochattools/discussions)

Approved beta participants may clone and evaluate the designated snapshot locally under the repository's beta license. The public documentation does not grant unrestricted installation, production, redistribution, or commercial-use rights.

## ProChat Workbench

ProChat Workbench is a **free, self-hosted public prerelease** licensed under `AGPL-3.0-only`.

Use this path to:

- understand guarded local project work through ChatGPT;
- review setup and repository guidance;
- inspect contribution expectations;
- report issues or join discussions.

For current product questions, use the Memory, Memory for QA, and Workbench paths above.
