# SaaSKit & ProKit Documentation

These docs exist to help founders implement the kits correctly once the decision to build is clear.

If you are starting from zero, begin with [SaaSKit](/docs/saaskit). It is the default implementation path for most non-technical founders who want the full production-ready foundation.

Use [ProKit](/docs/prokit) only if you already know you want the lighter engine layer and plan to control more of the launch structure yourself.

If you have not decided what to build yet, start with [Starting Point](/starting-point). If the decision is already clear and you want the live product foundation, start with [SaaSKit](/kits/saaskit).
