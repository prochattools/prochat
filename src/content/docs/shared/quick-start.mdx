Use this page when you want immediate momentum. The goal is to get the selected kit running locally, confirm the critical systems are wired, and then move into the right follow-up docs.

## Choose the right product first

- Choose [SaaSKit](/docs/saaskit) if you want the default production-ready founder path
- Choose [ProKit](/docs/prokit) only if you intentionally want the lighter engine layer

If the product decision is still unclear, stop here and use [Starting Point](/starting-point) before you begin setup.

## Before you start

Make sure you have:

- Node 20 installed
- access to a Postgres database
- the environment variables for auth, billing, and email
- the repository you plan to use

If you want a fast proof-of-life before full setup, use [Try in 2 minutes](/docs/shared/try-in-2-minutes).

## Quick start sequence

1. Clone the product you actually plan to build on:
   - SaaSKit: `git clone https://github.com/stevewesthoek/saaskit`
   - ProKit: `git clone https://github.com/stevewesthoek/prokit`
2. Install dependencies with `npm install`
3. Copy the environment file and fill the required values for database, Clerk, Stripe, and email
4. Start the app locally with `npm run dev`
5. Confirm the homepage loads, auth routes respond, and the main dashboard shell renders
6. Move into the product-specific setup docs before you change business logic or UI

## What to check before moving on

- the app boots without environment errors
- the database connection works
- sign-up or sign-in routes load correctly
- billing configuration is present, even if you are still using test mode
- you know which docs page you are following next

## What to do next

- Read [SaaSKit Quick Start](/docs/saaskit/quick-start) if you chose SaaSKit
- Read [ProKit Quick Start](/docs/prokit/quick-start) if you chose ProKit
- Use [Shared Configuration](/docs/shared/configuration) when environment setup is the next blocker
- Use [Shared Deployment](/docs/shared/deployment) when local setup is working and you are planning the production handoff
