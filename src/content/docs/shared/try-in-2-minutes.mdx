This quick walkthrough proves a sellable starter can boot locally before you commit to deeper setup.

## Try ProKit

```bash
git clone https://github.com/stevewesthoek/prokit
cd prokit
```

```bash
npm install
npm run dev
```

Open http://localhost:3000 to confirm the application boots and the local dashboard is reachable.

## Try SaaSKit

```bash
git clone https://github.com/stevewesthoek/saaskit
cd saaskit
npm install
npm run dev
```

Open http://localhost:3000 to confirm the application boots and the local dashboard is reachable.

## Deploy when you are ready

1. Push your branch to GitHub.
2. Connect the repo in Vercel, select the branch, and add the environment variables from `.env.example`.
3. Let Vercel build using `npm run build`.

After deployment, continue with the product-specific [Quick Start guide](/docs/shared/quick-start) or the [shared deployment reference](/docs/features/deployment).
