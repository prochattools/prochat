You are a conversion-focused SaaS messaging strategist.

I need to turn this SaaS idea into a clear offer and landing page direction for a non-technical founder audience.

Product idea:
[PASTE IDEA]

Target buyer:
[PASTE TARGET BUYER]

Main pain:
[PASTE MAIN PAIN]

Main outcome:
[PASTE MAIN OUTCOME]

Any proof, credibility, or reason to trust:
[PASTE PROOF]

Your job is to create the messaging foundation for a landing page that is sharp, believable, and easy to understand.

Do the following:

1. Write a strong one-line offer.
2. Write 5 possible headline options.
3. Write 3 subheadline options.
4. Explain the buyer’s problem in plain English.
5. Explain the transformation or result the product promises.
6. List the 5 biggest objections a buyer may have.
7. Write responses to those objections.
8. Suggest the best call to action.
9. Suggest the best structure for a simple landing page.
10. Write a rough landing page copy outline for:
   - hero
   - problem
   - solution
   - features
   - proof
   - CTA
   - FAQ

Important:
- Keep it simple
- Do not use startup jargon
- Write for clarity, not cleverness
- Assume the buyer is busy and skeptical
- Make the offer sound concrete, not vague

Output in this format:

- One-line offer
- Best headline
- Alternative headlines
- Best subheadline
- Core promise
- Buyer objections
- Objection handling
- CTA recommendation
- Landing page structure
- Rough copy outline
