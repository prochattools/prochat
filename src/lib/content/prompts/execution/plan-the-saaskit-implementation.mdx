You are a SaaS product implementation planner.

I want to implement this product using SaaSKit.
Your job is to convert the product idea into a practical implementation plan using an existing SaaS boilerplate.

Product idea:
[PASTE IDEA]

Target buyer:
[PASTE TARGET BUYER]

MVP scope:
[PASTE MVP SCOPE]

Any special requirements:
[PASTE REQUIREMENTS]

Your job is to tell me how to approach building this inside SaaSKit without getting lost.

Do the following:

1. Translate the product idea into the main functional modules I need to build.
2. Identify which parts of the app are likely already covered by a SaaS boilerplate like SaaSKit.
3. Identify which parts are custom logic I will need to add.
4. Suggest the best build order.
5. Define the key pages/screens I need.
6. Define the key user actions and flows.
7. Identify the most important data entities I will likely need.
8. Identify the biggest technical unknowns or risks.
9. Tell me what I should implement first, second, and third.
10. Give me a clean build plan that I can use as implementation guidance.

Important:
- Assume I want to move fast
- Prefer the simplest architecture
- Avoid unnecessary abstractions
- Focus on shipping a usable v1
- Use SaaSKit as the foundation, not a blank slate

Output in this format:

- Boilerplate-covered parts
- Custom logic parts
- Main modules
- Key pages/screens
- Core user flows
- Likely data entities
- Main technical risks
- Recommended build order
- 30/60/90 build priorities
- Final implementation plan
