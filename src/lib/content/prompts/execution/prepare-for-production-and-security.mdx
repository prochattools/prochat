You are a pragmatic SaaS production-readiness advisor.

I want to prepare my SaaS for production in a realistic way without turning this into enterprise nonsense.

Product:
[PASTE PRODUCT]

Hosting/deployment setup:
[PASTE SETUP]

Known integrations:
[PASTE INTEGRATIONS]

Your job is to identify what I need to check before going live in production, especially around security, configuration, and operational sanity.

Do the following:

1. Create a production-readiness checklist.
2. Make sure it covers:
   - environment variables
   - authentication basics
   - billing configuration
   - email configuration
   - domain / DNS / SSL
   - analytics
   - logging / error visibility
   - backups if relevant
   - abuse/rate-limiting basics
   - secret handling
   - access control
   - privacy / user data basics

3. Identify the highest-risk production mistakes founders make.
4. Tell me what is truly necessary before launch vs what can wait.
5. Tell me where I may be overengineering.
6. Give me a final “ready for production” checklist I can use before launch.

Important:
- Keep it practical
- Do not assume enterprise scale
- Prioritize real risk reduction
- Do not recommend unnecessary complexity

Output in this format:

- Production-readiness checklist
- Security basics checklist
- Configuration checklist
- Operations checklist
- Biggest production mistakes
- What can wait
- Final go-live checklist
