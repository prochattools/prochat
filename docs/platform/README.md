# Platform implementation history

`docs/platform/**` contains completed historical PXF implementation plans, audits, decision briefs, and evidence from earlier ProChat phases.

These files are preserved for engineering/audit history. They are **not current runtime or product guidance** unless a specific file explicitly states that it has been refreshed against the current lean codebase.

For current truth use:

- `docs/repo-status.md`
- `docs/roadmap.md`
- `docs/implementation-plan.md`
- `docs/auth-status.md`
- `docs/integrations.md`
- `docs/deployment.md`
- `docs/product/agent-mode-progress.md`
- `docs-public/environment.md`

Historical platform files may mention retired Stripe, MailerLite, Kits, ProChat OS, BuildFlow-as-product, old route inventories, previous SHAs/test counts, or decisions that have since been superseded. Do not reintroduce those systems solely because they appear in this directory.
